# Codexa Docs

Codexa is an AI-powered release-risk investigation platform: a VS Code extension plus a web dashboard, sharing one FastAPI backend. (Early blueprint name: "ShipShield".)

Docs are written one file per phase so progress and decisions stay traceable.

| Phase | Title | Status |
|---|---|---|

| [2](phase-2.md) | Project setup and architecture | Planned |
